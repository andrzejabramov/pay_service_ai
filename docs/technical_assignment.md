# 📋 СБП C2B Agent — Техническое задание (MVP)

> **Статус**: В разработке  
> **Среда**: Тестовый стенд Альфа-Банка  
> **Сценарий**: Статический QR-код с открытой суммой + вебхук + возвраты  
> **Дата актуализации**: `{{DATE}}`

---

## 🎯 Цель MVP

Реализовать минимальный рабочий контур приёма платежей через СБП:
1.  Генерация статического QR-кода (сумма вводится плательщиком)
2.  Получение вебхука об оплате с идентификацией плательщика/поставщика
3.  Возврат платежа по запросу
4.  Вся коммуникация — через API Альфа-Банка (тест)

---
